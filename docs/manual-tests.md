# Ручная проверка ExplorerOne 0.2.0

Этот чек-лист предназначен для повторной проверки опубликованного архива на Windows 11 x64. Результаты выполненных прогонов находятся в [verification.md](verification.md); незаполненные пункты остаются сценариями для ручной проверки. Записывайте версию Windows и `ExplorerFrame.dll` для каждого прогона.

## Прямое открытие папок

- [ ] Запустить ExplorerOne от обычного пользователя и убедиться, что включён пункт «Открывать папки сразу во вкладках».
- [ ] Открыть обычную локальную папку стандартным действием Windows (например, из Проводника, `Win+E` или ярлыка). Папка должна появиться в новой вкладке существующего окна Проводника, а эта вкладка — стать активной.
- [x] Проверить команду «Показать в папке» с файлом. Файл должен быть выделен в новой активной вкладке; прежние вкладки, их расположения и выделения должны сохраниться.
- [ ] Повторить для путей с кириллицей, пробелами, `#` и буквальным `%`, а также для команды открытия из браузера или другого приложения.
- [x] Отправить несколько запросов одновременно и подряд. Проверить соответствие каждой вкладки своему запросу, отсутствие дубликатов и сохранность исходных вкладок.
- [x] Убедиться, что при прямом открытии не появляется отдельное окно Проводника и новая вкладка не проходит через «Главную».
- [x] Запустить отдельный процесс через `explorer.exe /n` и `/n,/select`. Проверить скрытие источника с первого наблюдения, прямое создание вкладки с папкой и перенос выделения. Этот резервный путь имеет большую задержку; замеры приведены в отчёте.
- [ ] Проверить обычное открытие, когда подходящего окна Проводника ещё нет. Windows должна создать первое окно с запрошенной папкой; следующий запрос при работающем ExplorerOne должен открыть вкладку.
- [ ] Выключить прямое открытие в меню, повторить запрос, затем включить его снова и проверить прямой маршрут.
- [ ] Закрыть ExplorerOne и убедиться, что Windows продолжает открывать папки обычным способом. Снова запустить приложение и проверить прямое открытие.
- [x] Перезапустить Проводник, не завершая ExplorerOne; после восстановления оболочки проверить открытие папки в том же сеансе и процессе Проводника, который обслуживает рабочий стол.
- [ ] При неподдерживаемом профиле `ExplorerFrame.dll` убедиться, что прямой маршрут не включается и остаётся доступен резервный перенос.

Папка считается открытой после отображения её содержимого. Появление окна или вкладки само по себе не подтверждает готовность папки; единичный замер не является гарантией задержки.

## Установка и автозапуск

- [ ] Распаковать опубликованный архив в постоянную папку и запустить ExplorerOne без запроса повышения прав.
- [ ] Включить «Запускать при входе в Windows», выполнить повторный вход и проверить запуск ExplorerOne.
- [ ] Выключить автозапуск и убедиться, что ExplorerOne больше не запускается при следующем входе.
- [ ] Убедиться, что настройка автозапуска меняет только собственную запись ExplorerOne и не заменяет ассоциации папок Windows.
