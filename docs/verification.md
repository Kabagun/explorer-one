# Результаты проверки 0.1.0

Проверка выполнена 24 октября 2026 года. Это предварительная версия: успешная сборка и отдельные сценарии не доказывают совместимость со всеми версиями Проводника.

## Автоматические проверки

- .NET SDK 10.0.402, Windows x64.
- `dotnet run --project tests/ExplorerOne.Tests -c Release`: 45 из 45 тестов прошли.
- `dotnet build ExplorerOne.sln -c Release`: успешно, без предупреждений и ошибок.
- Тесты очереди проверяют выбор и смену основного окна, одновременные запросы, задержку повторов, отмену и отказ COM-снимка.
- Тесты запрета закрытия проверяют полный перенос всех вкладок, неизменность исходной папки и выделения, наличие отдельных целевых вкладок. Потеря или изменение любого из этих условий запрещает закрытие.
- Дополнительные тесты проверяют однократное декодирование файловых URL, UNC, кириллицу и сохранение буквальных `%`/`#` в обычных путях.

## Проверка реального Проводника

В интерактивном сеансе Windows 11 x64, сборка 26300, выполнен изолированный smoke-тест COM-компонента и очереди. Тест создавал собственные временные папки и новые окна, ограничивал переносы списком этих окон и не запускал глобальный сбор пользовательских окон.

Успешно проверены:

- перенос обычной папки с кириллицей и `#` в имени в нативную вкладку;
- сохранение выделенного тестового файла, включая получение настоящего имени при скрытых расширениях;
- перенос всех вкладок уже существующего окна с несколькими вкладками;
- последовательная обработка одновременно созданных окон через реальный `WindowCoordinator`;
- перенос пространств имён «Главная», «Этот компьютер» и «Корзина»;
- сохранение исходного окна при недействительном целевом окне и при отмене до переноса;
- неизменность набора ранее открытых пользовательских окон Проводника.

Тестовые окна после проверки закрыты. Это проверка механизма на одной системе; она не заменяет длительную эксплуатацию и весь чек-лист интерфейса.

## Область ручной проверки

Полный [чек-лист](manual-tests.md) остаётся отдельной ручной проверкой. В частности, автозапуск, работа браузерной команды «Показать в папке», физическое нажатие Win+E, виртуальные рабочие столы, сетевые ресурсы и реальный перезапуск explorer.exe не считаются проверенными только на основании автоматических тестов.

При проверках не включался автозапуск, не изменялась конфигурация ExplorerTabUtility и не закрывались пользовательские окна Проводника.
