# ExplorerOne icon

`explorer-one.png` is the transparent master image, generated with ChatGPT's built-in image generation. `explorer-one.ico` packages transparent PNG frames at 16, 20, 24, 32, 40, 48, 64, 96, 128 and 256 pixels for Windows.

The same ICO is embedded in the executable and as `ExplorerOne.AppIcon.ico` for the tray. The tray loads the size requested by Windows and owns a disposable copy.

## Generation prompt

```text
Use case: logo-brand. Asset type: a finished Windows desktop application icon for ExplorerOne, a small utility that combines File Explorer windows into tabs inside one window. Generate ONE original polished icon, not a presentation, not a mockup and not a contact sheet. Subject: a single bold recognizable warm yellow-gold file folder, with two clean cool blue folder-tab shapes integrated into one unified silhouette to suggest many windows becoming one. Style: restrained Windows 11 Fluent-inspired dimensional illustration, premium professional desktop utility, crisp edges, subtle satin highlights, very simple geometry, excellent legibility at 16, 24 and 32 pixels. Composition: square canvas, front three-quarter view with minimal perspective, centered icon occupying about 85 percent of canvas with safe margins. Actual transparent background with preserved alpha channel, no background plate, no white matte, no checkerboard drawn into the image. No text, no letters, no numbers, no watermark, no unrelated symbols, no arrows, no badges, no floating extra windows, no excessive glow or large soft shadow. Keep the outline compact and clear on both light and dark taskbars.
```
